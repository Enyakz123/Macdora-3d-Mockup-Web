The Macdora TypeScript preprocessing and mask composition implement the
normalization described by rembg's U2netpSession (320 x 320 RGB, ImageNet
mean/std, min/max output normalization). Inference runs in a Web Worker
using ONNX Runtime Web 1.23.2 (Microsoft, MIT).
See ONNXRUNTIME-LICENSE.txt for the runtime's license.
https://github.com/microsoft/onnxruntime

The lightweight model may need manual refinement on fine hair, translucent
objects, or complex backgrounds. No remote inference API is called.
