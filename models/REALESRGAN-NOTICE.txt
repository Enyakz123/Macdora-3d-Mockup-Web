All 101 ONNX initializer tensors were checked byte-for-byte against tensor

ONNX checker passed. Graph ops: Add, Constant, Conv, DepthToSpace, PRelu, Resize.

Input/output: RGB NCHW float32 [0,1], dynamic H/W -> 4H/4W.
Runtime: ONNX Runtime Web 1.23.2 (MIT; ONNXRUNTIME-LICENSE.txt).
2x output uses the same 4x network and averages each 2x2 result pixel block.
Tiles have a 128px core with 34px of source context on each internal edge,
covering the full 34-convolution receptive radius; context is discarded.
Alpha is resampled separately; transparent RGB is extended from visible
pixels before inference to reduce black fringes. No alpha is generated by AI.

The 4.9 MB ONNX file is distributed in the static site and fetched only when
Super resolution runs. A full size/SHA-256 check precedes persistent cache use.
Only the model is downloaded. Photos are never uploaded to an inference API.
Models estimate detail and can alter fine writing, faces and textures; inspect
the preview. This feature does not claim equivalence to Affinity's own model.
